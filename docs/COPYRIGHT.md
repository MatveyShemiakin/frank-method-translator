# Авторские права и безопасное использование

Проект технически способен обработать длинный текст, но пользователь отвечает за законность использования исходника.

Рекомендуемые сценарии:

- собственные статьи, лекции, заметки;
- тексты public domain;
- тексты с лицензией, разрешающей адаптацию/переработку;
- материалы, на которые у пользователя есть письменное разрешение;
- ограниченные фрагменты для личной учебной работы, если это разрешено применимым законодательством.

Не рекомендуется:

- выкладывать в открытый доступ адаптированные версии современных книг без разрешения;
- публиковать полные статьи из платных журналов;
- обходить DRM или закрытые платформы;
- удалять сведения об авторе и источнике.

Практическая защита проекта:

1. Добавьте в интерфейс чекбокс подтверждения прав, если сайт будет публичным.
2. Ограничьте размер одного запроса для публичной версии.
3. Логируйте только технические метаданные, не сохраняйте полный текст без согласия пользователя.
4. Добавьте Terms of Use, если сайт будет доступен сторонним пользователям.
